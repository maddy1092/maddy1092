- **Multi-tenant RAG platform:** document ingestion, structure-aware chunking, embeddings and vector search, with multiple LLMs for grounded answers and per-tenant data isolation.
- **Real-time AI conversation analytics:** a Django/DRF backend that turns mobile audio chunks into speaker-labelled transcripts with speech-to-text and an LLM, streamed live to a manager dashboard over WebSockets.
- **HIPAA-regulated healthcare platform:** rebuilt in Next.js with SAML SSO, two-factor authentication and role-based access.
- **Checkout SDK:** added Apple Pay, Google Pay, Samsung Pay and STC Pay to a card-only checkout.
